# Robot Warehouse Navigator

A COAL (Computer Organization and Assembly Language) semester project developed using **x86 Assembly Language (MASM)** and the **Irvine32 Library**.

## About the Project

Robot Warehouse Navigator is a warehouse navigation system in which a robot moves through a grid-based warehouse, avoids obstacles, and completes delivery tasks.

The project demonstrates the use of assembly language concepts through an interactive program with a menu system, robot name entry, and gameplay interface.

## Features

- Interactive main menu
- Robot name entry screen
- Grid-based warehouse navigation
- Robot movement using keyboard arrow keys
- Obstacles that the robot must avoid
- Delivery task management and counter
- Visual interface with custom background images
- Simple and user-friendly controls

## Technologies Used

- **Language:** x86 Assembly Language
- **Assembler:** MASM (Microsoft Macro Assembler)
- **Library:** Irvine32
- **IDE:** Microsoft Visual Studio
- **Platform:** Windows

## How to Run

1. Download or clone this repository.
2. Open the project in Microsoft Visual Studio.
3. Make sure MASM and the Irvine32 library are properly configured.
4. Check that the required image and other asset files are available in their correct locations.
5. Build and run the project.

**Note:** The Irvine32 library and MASM configuration are required to compile and run this project.

## Project Structure

The repository contains the assembly source code, project files, required assets, and project documentation.

## Learning Objectives

- Understand x86 Assembly Language programming.
- Apply registers, memory, and control flow instructions.
- Work with procedures and modular programming.
- Implement keyboard input and screen output.
- Develop an interactive application using MASM and Irvine32.
